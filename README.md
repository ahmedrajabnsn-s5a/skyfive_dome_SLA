# A2G SLA Monitor

Password-protected web copy of the SKYFive A2G SLA dashboard (availability & throughput service levels).

All dashboard content and flight tracks are encrypted (AES-256-GCM, key derived from the password with PBKDF2-SHA256)
and decrypted only in the viewer's browser. Ask the dashboard owner for the password.

This is a snapshot; it is refreshed when a new build is pushed.
